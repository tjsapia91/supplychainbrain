# _batch-data — Prizm batch export drop folder

Drop the **Prizm batch-tracking CSV** here (Prizm ERP → Reports → Generated Reports →
Batch Code Tracking → CSV export). Newest file wins.

This replaces the external **Batch Code Lookup** web app — the full lot dataset now lives
in the brain. Look codes up with **`/batch-lookup <code | item# | UPC | PPO#>`**, or just
ask "look up batch NFMD03152026X". Conventions + live decisions live in
[[01 Purchasing & Inventory/(C) Batch Code Tracker]].

*(CSV data files here are gitignored by size if large; the tracker note + command are versioned.)*
